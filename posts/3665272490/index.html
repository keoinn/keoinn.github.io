本文件說明如何將 n8n 部署至 Google Cloud Run，並使用 Supabase PostgreSQL 作為資料庫，而非 Google Cloud SQL。架構圖如下：

1. 建立 Supabase 帳號與連線資訊

第 1/5 步：點擊 "New project" 按鈕

點擊"New project"按鈕

第 2/5 步：設定資料庫與伺服器區域資訊

設定基本資訊後建立資料庫

小提示

  • Project name: 設定為 cloudrun-n8n
  • Database password: 可以透過 "Generate a password" 建立隨機密碼，並另存於記事本上。
  • Region: 設定為 "Northeast Asia (Tokyo)"

第 3/5 步： 點擊 Connect 按鈕

點選"Connect"

第 4/5 步： 依照下列選項找出對應的連線資訊

選擇連線方式;

步驟

  1. 點擊 "Driect"
  2. Connection Method 選擇 "Session pooler"
  3. Type 選擇 "URI"

完成

5. 完成部署後的設定

第 1/6 步： 透過網址進入 n8n

透過上一章取得的 n8n 服務網址觸發 CloudRun 服務啟動

觸發 Cloud Run 服務;

大約等待 30 秒至 2 分鐘後，對著瀏覽器按下 F5 重新整理。

第 2/6 步： 設定管理者帳號

依照欄位填寫資訊，並按下 "Next" 進行下一步

填寫資訊並且註冊

注意
Email 欄位請使用可以收信的信箱，後續需要透過此信箱接收 Licence Key

第 3/6 步： 填寫 n8n 官方的調查資訊

依照欄位填寫資訊，並按下 "Get started" 進行下一步

填寫問券

第 4/6 步： 填寫 License Key 接收信箱

確認收信信箱是否正確，後點擊 "Send me a free license key“\ 接收序號

確認收信信箱

第 5/6 步： 登入自己填寫的 Email 尋找 license key

  1. 看到以下資訊後表示 n8n 已經將 license key 寄送至信箱中
    金鑰送出提示
  2. 找出 license key 信件 (主旨：Your free n8n license key to unlock selected paid features)
    License Key

第 6/6 步： 進入設定並登錄 License key

  1. 主畫面左下角 齒輪 icon ⮕ Usage and plan
    選擇 Usage and plan 功能
  2. 點擊主畫面中 "Enter activation key"
    點擊Enter activation key
  3. 輸入 License Key 並點擊 "Activate"
    輸入Licence Key並啟用
  4. 完成後，主畫面會顯示 "Registered" Label
    Registered

完成
