【人工智慧雲端系統實務】關閉 Google Cloud 專案與移除帳單帳戶

Wayne Chang
Google Cloud Platform人工智慧雲端系統實務學習筆記 學習筆記 人工智慧雲端系統實務 Google Cloud Platform

發表於：2026年8月25日

更新於：2026年8月26日

在 Google Cloud Platform（GCP）試用期的最後一週，只要依照這套流程依序完成「資料備份、專案轉移、關閉專案、關閉帳單帳戶，到最後移除帳號」，就能守住你的荷包，避免因為學完後忘記關閉資源而產生非預期的扣款與浪費。

這份教學將帶你掌握關閉帳號時必須執行的 5 個關鍵步驟，接下來就跟著我們一步步完成吧！

1. 進行資料備份

在關閉專案前，最重要的第一步就是將雲端上的重要資產完整匯出。一旦專案被刪除，所有未備份的資料在保留期過後將永久遺失且無法復原。

  • Cloud Storage 儲存桶檔案
    • 尋找路徑：左側導覽選單 ⮕ Cloud Storage ⮕ Buckets
    • 操作建議：將重要設定檔、靜態資源或媒體檔案下載至本機，亦可透過 gcloud storage cp 指令進行批次備份。
  • Compute Engine 磁碟與程式碼
    • 尋找路徑：左側導覽選單 ⮕ Compute Engine ⮕ VM 執行個體
    • 操作建議：連線進入虛擬機將原始碼打包下載，或對磁碟建立快照 (Snapshots) 以備日後重現環境。
  • 資料庫內容 (Cloud SQL / Firestore)
    • 尋找路徑：左側導覽選單 ⮕ Databases ⮕ Cloud SQL（或 Firestore）
    • 操作建議：利用控制台內建的「匯出 (Export)」功能產出 SQL Dump 或 JSON 資料，再下載至地端保存。

2. 釋放與刪除資源

備份完成後，建議手動依序刪除專案內所建立的各項雲端資源。特別是「保留未使用的靜態 IP」仍會持續計費，提早清理能確保在專案正式關閉過渡期間不會產生任何隱藏費用。

  • Compute Engine（VM 執行個體）
    • 尋找路徑：左側導覽選單 ⮕ Compute Engine ⮕ VM 執行個體
    • 操作建議：勾選正在運行的 VM，點選上方「刪除 (Delete)」。刪除 VM 時，請確認連帶掛載的開機磁碟 (Boot Disk) 一併移除。
  • 外部靜態 IP 位址 (External Static IPs)
    • 尋找路徑：左側導覽選單 ⮕ VPC 網路 (VPC Network) ⮕ IP 位址 (IP Addresses)
    • 操作建議：靜態 IP 若處於保留但未綁定狀態會持續計費。勾選所有已保留的靜態 IP，點選上方「釋放靜態位址 (Release Static IP)」。
  • 防火牆規則 (Firewall Rules)
    • 尋找路徑：左側導覽選單 ⮕ VPC 網路 (VPC Network) ⮕ 防火牆 (Firewall)
    • 操作建議：若有額外自訂的防火牆規則（如自訂開啟特定 Port），勾選後點選「刪除」；預設規則可隨專案關閉一併清除。
  • Cloud Run（無伺服器服務與工作）
    • 尋找路徑：左側導覽選單 ⮕ Cloud Run ⮕ 服務 (Services)
    • 操作建議：勾選部署的服務與工作 (Jobs)，點選上方「刪除」，避免後續觸發呼叫或背景排程。

3. 關閉專案

確認資料都已經完成備份並且移除相關資源後，透過以下的流程逐步把所有專案進行關閉。

第 1/5 步：打開專案選取器

打開專案選取器
  • 打開專案選取器 ⮕ 選擇全部分頁 ⮕ 選取要關閉的專案。

第 2/5 步：開啟專案設定

專案歡迎頁面並進入專案設定
  • 確認關閉專案名稱是正確 ⮕ 標題列選擇...按鈕 ⮕ 專案設定。

第 3/5 步：點擊關閉按鈕

畫面轉跳至IAM與管理，點擊關閉按鈕

第 4/5 步：輸入專案 ID 後進行關閉程序

輸入專案 ID 再次確認關閉專案

專案 ID 是不帶有空白的專案唯一序號，顯示於輸入對話框上方 (圖中劃線處)。

第 5/5 步：專案關閉完成

專案關閉完成

專案關閉流程後，會變成「待刪除」狀態，
當誤刪專案時，可以在 管理資源頁面 進行恢覆。

完成

請繼續完成其他專案關閉流程，直到所有閒置或是計費專案完全關閉。

4. 關閉帳單帳戶

當所有帳號內的專案都完成關閉流程後，進行以下流程將帳單帳戶進行關閉。

第 1/5 步： 透過帳單管理網址進入管理介面

透過網址方式進入 帳單管理 介面。

Google Cloud 帳單管理

完整 URL https://console.cloud.google.com/billing?organizationId=0&orgonly=true&supportedpurview=project

第 2/5 步： 進入帳單帳戶管理介面，並選擇要關閉的帳戶

選擇要關閉的帳戶

點擊「要關閉的帳單帳戶」。

第 3/5 步： 點擊管理帳單帳戶

點擊「管理帳單帳戶」按鈕

點擊「管理帳單帳戶」進入帳單帳戶的儀表板。

第 4/5 步：從帳單帳戶管理介面點擊關閉帳單帳戶按鈕

確認帳單連結專案情況並執行關閉流程

① 確認「與這個帳單帳戶連結的專案」是空白的，如果還有資料時表示尚有專案未完成關閉的動作。
② 點擊「關閉帳單帳戶」按鈕，進行關閉流程。

第 5/5 步： 確認帳單帳戶資訊並執行關閉帳戶流程

確認計費狀況並執行關閉帳戶確認動作

在下方對話框輸入「關閉」並且點擊「關閉帳單帳戶」按鈕，執行關閉帳單帳戶的流程。

圖片上紅色劃線處解說：
關閉帳單帳戶的對話視窗上，將匯總當前該帳單帳戶的使用情形由上至下順序解釋 (圖中紅色底線部分，由上至下並且由左至右順序解釋)：

① 目前帳單帳戶實際上連結的專案 (運行中，尚未變成待刪除狀態的專案)。
② 上個月的計費情形。
③ 本月使用狀況且尚未結清的費用。
④ 完整計費停止時間為最多 48 小時。

完成

完成帳單帳戶關閉動作後，會出現當前畫面表示當前帳單帳戶已經關閉完成。
如果需要可以執行第五步驟，刪除 Google 帳號。

5. 刪除 Google 帳號

第 1/2 步： 透過網址進入 Google 帳號管理介面

透過網址方式進入 Google 帳戶 介面。

Google帳戶介面

前往 Google 帳戶

完整 URL https://myaccount.google.com/
註： Google 帳戶是指的是 Gmail 帳號本身，非 Google Cloud 產品系列中的產品。

第 2/2 步： 進入資料和隱私權選項，選擇刪除帳號

找到刪除帳號的選項

從側欄選單選擇「資料和隱私權」⮕ 滾動中間畫面至最下方 ⮕ 選擇 「刪除您的 Google 帳戶」選項。

後續

後續就按照系統提示進行操作即可。

Q&A. 常見問題

Q1. 停用 Google Cloud 為什麼需要先關閉專案，再關閉帳單帳戶呢？

Google Cloud 服務上分成兩大部分，專案 與 帳單帳戶，之間關係是專案需要進行付款行為時，向指定的帳單帳戶進行請款，其中：

① 專案可以轉移給其他使用者。
② 專案可以變更請款的帳單帳戶。
③ 帳單帳戶跟隨 Google 主帳號，不能進行轉移。

在當前的 Google Cloud 帳戶政策下，要關閉帳單帳戶前，該帳戶不能有連結的專案在其中，因此需要先把 專案 進行關閉或是轉移後，在進行關閉帳單帳戶。

Q2. 關閉專案一定要進行資料的備份嗎？

不一定，需要備份與否則按照自己在雲端服務搭建的狀況決定，
原始碼部分都備份在 Github 上，但如果要保留 n8n 上的工作流，請先登入 n8n 後把工作流進行匯出。

Q3. 關閉專案前有需要移除已經申請的資源或是主機嗎？

不一定，關閉專案的過程中，Google Cloud 會自己停掉所有 VM 執行個體、靜態位址、Cloud Run 服務、API 服務 等資源。
但是，實際上完整停止專案所有資源是情況至多需要 48 小時，因此部分資源實體還是會繼續進行計費，如執行個體的存儲空間、靜態位址等，當帳戶內還有試用額度時且試用期限大於2天時，還是會優先使用試用金進行支付，實務上也是不會花到錢。

Q4. 有需要刪除 Google 帳號嗎？

視情況而定，如果 Google 帳號是申請來試用 Google Cloud 時可以考慮刪除帳號，畢竟新的 Google 帳號只能申請一次免費試用抵免額。

但是當前帳號是自己平時經常使用的 Google 帳號時，就千萬不要進行刪除的動作。

Q5. 不能直接刪除 Google Cloud 帳號就好嗎？

不行，Google Cloud 是一個服務，只能透過停用計費功能讓 Google Cloud 停下來收費。如果有疑慮請考慮刪除停用 Google 主帳號。

如果有其他問題時，可以在來信並且附上截圖進行說明，如果有需要或是情況特需時，會再整理問題紀錄在此頁面上。
